# Prism

A version control system specifically designed for Microsoft Word (.docx) documents, particularly focused on the needs of humanities and law students.

## Features (Planned)

- Parse and understand the structure of .docx files
- Generate human-readable diffs between document versions
- Smart merging of document changes
- Seamless conversion between docx and markdown formats
- Git-like version control tailored for document workflows
